# বাংলা লেখার ধরন — ETP

ETP-এর বাংলা হবে বাংলাদেশের সাধারণ ব্যবহারকারীর মুখের স্বাভাবিক, সহজ ও সম্মানজনক বাংলা। অনুবাদ যেন ইংরেজি বাক্যের ছাঁচে আটকে না থাকে।

## লেখার নিয়ম

- আগে অর্থ বুঝে নিজের স্বাভাবিক বাংলায় লিখুন; ইংরেজি শব্দ ধরে ধরে অনুবাদ করবেন না।
- ছোট, পরিষ্কার বাক্য লিখুন। এক বাক্যে একাধিক নির্দেশনা গুঁজে দেবেন না।
- ব্যবহারকারীর সঙ্গে ভদ্র ও আন্তরিকভাবে কথা বলুন। সাধারণ নির্দেশনায় “আপনি” ব্যবহার করুন।
- পরিচিত শব্দকে অকারণে কঠিন বা সাধুভাষার শব্দে বদলাবেন না।
- প্রযুক্তির পরিচিত শব্দ—যেমন এআই, কিউআর, অ্যাপ, লগইন, ইমেইল—প্রয়োজনে প্রচলিত রূপেই রাখুন।
- “যাত্রী”, “যাত্রা শুরু”, “গন্তব্য”, “বুকিং”, “ভাড়া”, “খালি আসন”, “খরচের হিসাব”—এ ধরনের পরিচিত শব্দ ব্যবহার করুন।
- “অনুসন্ধান”, “অগ্রগমন”, “উগম”, “ভ্রমণকর্তা” বা অস্বাভাবিক আক্ষরিক অনুবাদ এড়িয়ে চলুন। প্রসঙ্গ অনুযায়ী “খুঁজুন”, “ছাড়ার সময়”, “কোথা থেকে যাবেন”, “ভ্রমণকারী/যাত্রী” লিখুন।
- বোতাম ও ছোট লেবেল সংক্ষিপ্ত রাখুন: “খুঁজুন”, “বুক করুন”, “বিস্তারিত দেখুন”, “আবার চেষ্টা করুন”।
- সংখ্যা, টাকা, তারিখ ও সময় দেখানোর ক্ষেত্রে নির্বাচিত ভাষার locale ব্যবহার করুন।
- অনুবাদে মূল তথ্য, মূল্য, শর্ত, নিরাপত্তা বা বুকিংয়ের অর্থ বদলানো যাবে না।
- অনিশ্চিত অনুবাদ অনুমান করে লিখবেন না; পর্যালোচনার জন্য চিহ্নিত করুন।

## কণ্ঠস্বরের নমুনা

| ইংরেজি ধারণা | ETP-তে স্বাভাবিক বাংলা |
|---|---|
| Select origin | কোথা থেকে যাবেন |
| Select destination | কোথায় যাবেন |
| Search buses | বাস খুঁজুন |
| Continue to payment | পেমেন্টে যান |
| No buses found | কোনো বাস পাওয়া যায়নি |
| Something went wrong | একটি সমস্যা হয়েছে |
| Plan my trip | ভ্রমণের পরিকল্পনা তৈরি করুন |
| View details | বিস্তারিত দেখুন |
| Try again | আবার চেষ্টা করুন |

## গ্রহণযোগ্যতার মান

বাংলা লেখা পড়ে বাংলাদেশের একজন সাধারণ ব্যবহারকারী যেন প্রথমবারেই বুঝতে পারেন কী করতে হবে, কী ঘটেছে এবং পরের ধাপ কী। আক্ষরিক অনুবাদের চেয়ে স্বাভাবিক অর্থ ও ব্যবহারকারীর বোঝাপড়াকে অগ্রাধিকার দিন।
